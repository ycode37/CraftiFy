## 📌 What is this project?

CraftiFy is a web application designed for artisans, hobbyists, and creators to showcase their craft work, manage their projects, and connect with a community of like-minded creators. It provides a simple, organized space to display creative work and keep track of ongoing projects.

---

## ❓ What problem does it solve?

Creators and hobbyists often struggle with:

- No centralized place to showcase their craft projects
- Difficulty organizing and tracking multiple ongoing projects
- Limited ways to connect with other creators or an audience
- Scattered documentation of materials, steps, and progress

**CraftiFy** solves this by offering:

- 🎨 A dedicated space to showcase craft projects with images and details
- 📋 Simple project organization and tracking
- 👥 A way to connect with a community of creators
- 🔍 Easy discovery of projects and ideas

## 🚀 How to Run This Project

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm or yarn
- Git

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/ycode37/CraftiFy.git
   cd CraftiFy
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**

   Create a `.env` file in the root directory and add any required configuration, for example:
   ```env
   PORT=5000
   DATABASE_URL=your_database_url_here
   ```

4. **Run the project**
   ```bash
   npm start
   ```

5. **Open in your browser**

   Visit `http://localhost:3000` (or the port shown in your terminal) to use the app.

> ⚠️ _If your project uses a different setup (e.g. separate client/server folders, `npm run dev`, etc.), update the steps above to match._
